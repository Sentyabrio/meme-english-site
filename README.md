# Meme English — сайт

Публичная страница приложения Meme English: политика конфиденциальности, условия, правообладателям, поддержка. Адрес `https://sentyabrio.github.io/meme-english-site/` стоит в App Store Connect и Google Play (политика конфиденциальности и поддержка). Страница закрыта от поисковиков (`noindex`), открывается по ссылке.

## hidden.json: настройки приложения без релиза

Файл правится прямо на GitHub: открыть `hidden.json` → карандаш → Commit changes.

```json
{
  "hidden": {
    "r_ig9u4z": "жалоба правообладателя 10.10.2026"
  },
  "analyticsOff": [],
  "adsOff": [],
  "adsEvery": 10
}
```

Приложение при каждом запуске скачивает файл и сохраняет его у себя, а применяет со следующего запуска. GitHub Pages обновляется за минуту-две после коммита. Запасной адрес на jsDelivr может отставать до 12 часов; обновить его сразу можно, открыв `https://purge.jsdelivr.net/gh/Sentyabrio/meme-english-site@main/hidden.json`.

### Что можно настроить

**`hidden` — убрать мемы.** Ключ — номер мема (он написан мелко внизу страницы «О меме» в приложении), значение — причина, для себя. Мем пропадает из ленты, из словаря и со страницы мема. Если человек остановился на скрытом меме, лента откроется со следующего. Вернуть мем — удалить строку.

**`analyticsOff` — выключить статистику** в указанных версиях приложения. Статистика в них не отправляется, даже если человек на неё согласился; его выбор при этом сохраняется и снова заработает, когда версию уберут из списка.

**`adsOff` — выключить рекламу** в указанных версиях.

**`adsEvery` — через сколько мемов показывать рекламу**, число от 3 до 100 без кавычек. Если строки нет, остаётся 10.

### Как записывать версии

| Запись | Какие версии |
|---|---|
| `"1.0.2"` | только 1.0.2 |
| `"<1.0.3"` | все до 1.0.3, сама 1.0.3 не входит |
| `"<=1.0.3"` | все до 1.0.3 включительно |
| `">1.0.3"` | все после 1.0.3 |
| `">=1.0.3"` | 1.0.3 и все после |
| `"1.0.0..1.0.4"` | с 1.0.0 по 1.0.4 включительно |
| `"*"` | все версии |

Записей в списке может быть несколько, срабатывает любая: `"adsOff": ["<1.0.2", "1.0.5"]` выключит рекламу в версиях до 1.0.2 и в 1.0.5. Версия — три числа через точку, как в магазине; номер сборки не учитывается.

### Если ошибиться

Файл, в котором хоть что-то не так (лишняя запятая, версия `1.0` вместо `1.0.0`, число в кавычках), приложение не примет целиком и продолжит работать с прошлым исправным. Ничего не упадёт, но и новая правка не сработает. Поэтому после каждого коммита GitHub проверяет файл теми же правилами (`tools/check_hidden.py`): если что-то не так, у коммита появится красный крестик и придёт письмо. Зелёная галочка — файл в порядке.

Скрытые мемы в следующем релизе стоит перенести в `collected/blocklist.json` репозитория приложения и пересобрать каталог: тогда картинки уйдут и из самой сборки.

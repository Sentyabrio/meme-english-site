# Meme English — сайт

Публичная страница приложения Meme English: политика конфиденциальности, условия, правообладателям, поддержка. Адрес `https://sentyabrio.github.io/meme-english-site/` стоит в App Store Connect (Privacy Policy URL и Support URL). Страница закрыта от поисковиков (`noindex`), открывается по ссылке.

## Как убрать мем из всех установленных приложений

Без нового релиза, правкой одного файла `hidden.json` прямо на GitHub (карандаш → Commit changes):

```json
{
  "hidden": {
    "r_ig9u4z": "жалоба правообладателя 10.10.2026",
    "drake": "сами решили"
  }
}
```

Ключ — номер мема (он написан мелко внизу страницы «О меме» в приложении), значение — причина, для себя. Приложение скачивает список при каждом запуске и прячет эти мемы со следующего запуска: из ленты, из словаря, со страницы мема. GitHub Pages обновляется за минуту-две после коммита.

Вернуть мем — удалить строку. Если запятая или кавычка сломают JSON, приложение такой список не примет и продолжит работать с прошлым, так что ничего не упадёт; но и новое скрытие не сработает, пока файл не починить.

В следующем релизе стоит перенести номера в `collected/blocklist.json` репозитория приложения и пересобрать каталог: тогда картинки уйдут из самой сборки.

# Meme English — сайт

Публичная страница приложения Meme English: политика конфиденциальности, условия, правообладателям, поддержка. Адрес `https://sentyabrio.github.io/meme-english-site/` стоит в App Store Connect и Google Play (политика конфиденциальности и поддержка). Страница закрыта от поисковиков (`noindex`), открывается по ссылке.

## hidden.json: настройки приложения без релиза

Файл правится прямо на GitHub: открыть `hidden.json` → карандаш → Commit changes. Обязателен только ключ `hidden`, остальные можно не писать.

Приложение при каждом запуске скачивает файл и сохраняет его у себя, а применяет со следующего запуска. GitHub Pages обновляется за минуту-две после коммита. Запасной адрес на jsDelivr может отставать до 12 часов; обновить его сразу можно, открыв `https://purge.jsdelivr.net/gh/Sentyabrio/meme-english-site@main/hidden.json`.

Пример со всеми ключами:

```json
{
  "hidden": {
    "r_ig9u4z": "жалоба правообладателя 10.10.2026"
  },
  "analyticsOff": ["<1.0.2"],
  "adsOff": [],
  "adsEvery": 10,
  "adUnits": {
    "android": "R-M-20184317-1",
    "ios": "R-M-20182829-1"
  },
  "update": {
    "suggest": ["<1.0.3"],
    "require": ["<1.0.1"],
    "message": "В словаре была ошибка, мы её исправили.",
    "android": "market://details?id=com.sentyabrio.meme_english",
    "ios": "https://apps.apple.com/app/id1234567890"
  },
  "fixes": {
    "memes": {
      "r_o2pr7l": {
        "translation": "Мой нос каждое утро в сезон аллергии",
        "why": "Новое объяснение шутки.",
        "glossary": {
          "allergy season": { "ru": "сезон аллергии" }
        }
      }
    },
    "words": {
      "make": { "ru": "делать", "note": "Make a mistake — с make, не с do." }
    }
  }
}
```

### Убрать мемы — `hidden`

Ключ — номер мема (он написан мелко внизу страницы «О меме» в приложении), значение — причина, для себя. Мем пропадает из ленты, из словаря и со страницы мема. Если человек остановился на скрытом меме, лента откроется со следующего. Вернуть мем — удалить строку.

### Статистика и реклама — `analyticsOff`, `adsOff`, `adsEvery`, `adUnits`

**`analyticsOff`** — версии, в которых статистика не отправляется, даже если человек на неё согласился. Его выбор при этом сохраняется и снова заработает, когда версию уберут из списка.

**`adsOff`** — версии без рекламы.

**`adsEvery`** — через сколько мемов показывать рекламу, число от 3 до 100 без кавычек. Без этого ключа — 10.

**`adUnits`** — запасной рекламный блок, если Рекламная сеть Яндекса заблокирует наш или выдаст новый. Номер блока из кабинета РСЯ, вида `R-M-20184317-1`, отдельно для Android и iPhone. Без ключа работают блоки, встроенные в приложение. На отладочных сборках всегда показывается демо-реклама, что бы здесь ни стояло.

### Обновить приложение — `update`

**`suggest`** — версии, которым один раз за запуск показывается окно «Вышла новая версия» с кнопками «Обновить» и «Позже».

**`require`** — версии, которые дальше не пускают: вместо приложения экран «Нужно обновить приложение» с одной кнопкой «Обновить». Уйти с него нельзя. Если версия попала в оба списка, действует `require`. Экран появляется только на той платформе, для которой ниже вписана ссылка (`android` или `ios`). Без ссылки `require` на этой платформе работает как `suggest`: окно с кнопкой «Позже». Так забытая ссылка или версия, которая ещё не вышла в одном из магазинов, не запрёт людей в приложении.

**`message`** — свой текст вместо стандартного, до 500 знаков. Стандартный: «В ней исправлены ошибки. Обновите приложение, когда будет удобно» для окна и «В этой версии нашлась ошибка, и её уже исправили. Чтобы продолжить, обновите приложение» для экрана.

**`android`**, **`ios`** — куда ведёт кнопка «Обновить». Разрешены только страницы магазинов: `market://details?id=…`, `https://play.google.com/…`, `https://www.rustore.ru/…`, `https://apps.rustore.ru/…` для Android и `https://apps.apple.com/…`, `itms-apps://apps.apple.com/…` для iPhone. Без ссылки Android открывает магазин, из которого обычно ставят приложения (`market://`, его понимают и Google Play, и RuStore). У iPhone ссылки по умолчанию нет, пока приложение не опубликовано: без неё кнопки не будет, человек увидит просьбу обновиться в магазине. После публикации в App Store стоит вписать сюда ссылку на страницу приложения.

`require` — крайняя мера: человек не сможет пользоваться приложением, пока не обновит его. Ставить, только когда новая версия уже доступна в магазине, иначе обновляться будет не на что.

### Исправить тексты — `fixes`

**`fixes.memes`** — тексты конкретного мема, по номеру: `titleRu` (название по-русски), `translation` (перевод), `literal` (дословный перевод), `why` (почему смешно), `origin` (откуда мем). Писать только то, что меняется, остальное останется как было. `titleRu`, `translation` и `why` пустыми быть не могут; `literal` и `origin` можно сделать пустыми (`""`) — тогда этот раздел исчезнет.

**`glossary`** внутри мема — слова этого мема. Поля: `ru` (перевод), `pos` (часть речи), `note` (заметка), `example` и `exampleRu` (пример и его перевод), `distractors` (ровно три неправильных варианта для тренировки). Можно исправить и слово из общего словаря только для этого мема: в остальных мемах оно останется прежним.

**`fixes.words`** — слова общего словаря, по ключу (слово маленькими буквами, как в приложении). Те же поля, что у `glossary`. Исправление действует во всех мемах, где слово взято из словаря.

Слово, которого в словаре нет, можно добавить, если указать `ru`. Слова, которые человек уже сохранил к себе, обновятся при следующем запуске: перевод, часть речи и заметка подтянутся из исправления, а прогресс повторения сохранится.

Номер мема или слова, которых в этой версии приложения нет, просто пропускается.

### Как записывать версии

| Запись | Какие версии |
|---|---|
| `"1.0.2"` | только 1.0.2 |
| `"<1.0.3"` | все до 1.0.3, сама 1.0.3 не входит |
| `"<=1.0.3"` | все до 1.0.3 включительно |
| `">1.0.3"` | все после 1.0.3 |
| `">=1.0.3"` | 1.0.3 и все после |
| `"1.0.0..1.0.4"` | с 1.0.0 по 1.0.4 включительно |
| `"*"` | все версии |

Записей в списке может быть несколько, срабатывает любая: `"adsOff": ["<1.0.2", "1.0.5"]` выключит рекламу в версиях до 1.0.2 и в 1.0.5. Версия — три числа через точку, как в магазине; номер сборки не учитывается.

### Если ошибиться

Файл, в котором хоть что-то не так (лишняя запятая, версия `1.0` вместо `1.0.0`, число в кавычках, пустой перевод), приложение не примет целиком и продолжит работать с прошлым исправным. Ничего не упадёт, но и новая правка не сработает.

Опечатку в названии ключа (`adsEvey` вместо `adsEvery`) приложение не заметит: незнакомые ключи оно пропускает, потому что их может добавить более новая версия. Такая правка просто не подействует.

Поэтому после каждого коммита GitHub проверяет файл (`tools/check_hidden.py`) — теми же правилами, что приложение, и вдобавок ищет незнакомые ключи. Если что-то не так, у коммита появится красный крестик и придёт письмо, а в журнале проверки будет написано, что именно не так. Зелёная галочка — файл в порядке.

Скрытые мемы и исправленные тексты в следующем релизе стоит перенести в само приложение (стоп-лист `collected/blocklist.json` и правки каталога) и убрать отсюда.
